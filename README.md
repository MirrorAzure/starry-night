# Starry Night

Лендинг Minecraft-сервера Starry Night — Vanilla+ проекта на Java Edition, созданного для творчества, исследования и долгосрочного выживания без вайпов.

Репозиторий содержит сайт сервера с информацией о проекте, участниках, способах получения проходки и правилах игры. На сайте также отображаются адрес подключения и расписание сезона.

Сайт написан на HTML, CSS и JavaScript.

Независимый проект, не связанный с Mojang Studios или Microsoft.
